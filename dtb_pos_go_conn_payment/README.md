# POS Go Conn payment (`dtb_pos_go_conn_payment`)

Card payments in Odoo Point of Sale through a PIN-pad, using the Databank Connection ("goconnection") program
running on the cashier PC.
/ Odoo POS-ийн картын төлбөрийг кассын компьютер дээр ажиллаж буй Databank Connection ("goconnection") програмаар
дамжуулан PIN-pad төхөөрөмжөөр хийнэ.

Setup, usage and the session-closing settlement: see the [repository README](../README.md).
/ Тохиргоо, хэрэглээ, session хаах үеийн тооцоо: [repository README](../README.md)-г үзнэ үү.
