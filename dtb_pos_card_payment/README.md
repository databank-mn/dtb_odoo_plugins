# POS card payment (`dtb_pos_card_payment`)

Card payments in Odoo Point of Sale through the Databank ePOS Android terminal app (the POS page opens a
`dtbodoo://` link handled by the app).
/ Odoo POS-ийн картын төлбөрийг Databank ePOS Android апп-аар хийнэ (POS хуудас `dtbodoo://` холбоос нээж, апп
хүлээн авна).

Setup and usage: see the [repository README](../README.md).
/ Тохиргоо, хэрэглээ: [repository README](../README.md)-г үзнэ үү.
