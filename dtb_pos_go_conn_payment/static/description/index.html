ePOS Plugin

 

Энэ модуль нь Databank Connection програмтай холбогдон ажиллана. Databank Connection програм нь кассын програм дээрээс Пин пад ашиглан банкны бэлэн бус гүйлгээ хийх боломжийг хангахахад зориулагдсан програм юм..

 

Давуу тал

  • Төлбөр, картын мэдээллийн аюулгүй байдлын PCI DSS LEVEL 1 стандартыг хангасан
  • Magstripe
  • ICC /Чип/
  • Contactless
  • PASS QR code /MPM/

Суулгах, Тохиргоо хийх заавар

 

1. Apps дотроос POS Go Conn payment үгээр хайж install хийнэ.

 

2. POS-ийн тохиргоонд байх Payment methods цэс дотор Databank GO гэсэн нэртэй төлбөрийн төрөл нэмэгдсэн байна. Дээр нь дарж ороод нэмэлт дараах тохиргоог хийнэ:

  • 'Journal' хэсэг банкны журнал сонгоно
  • 'Use a Payment' хэсэгт 'Databank Go connection' сонгогдсон байх ёстой

 

Хэрэглэх заавар

 

1. Захиалгаа бичээд төлбөр хийх хэсэг 'Databank Go' дээр 'Send' дарахад PINPAD төхөөрөмж рүү карт уншуулах команд илгээгдэнэ.

 

2. Төлбөр хийгдсэний дараа 'Payment successful' гэсэн төлөв орж VALIDATE товч идэвхижиж захиалга дуусгах боломжтой болно

 

Session хаахад тооцоо хаах (Settlement)

 

POS-ийн session хаах үед Databank Connection-ээр терминалын өдрийн тооцоог (batch) автоматаар хаах боломжтой. Хуучин суулгацад энэ нь анхдагчаар унтраалттай тул шинэчлэлийн дараа ажиллагаа өөрчлөгдөхгүй.

  • Payment methods → 'Databank Go connection' дотор 'Settle on session close' сонголтыг асаана.
  • Session хаах үед Databank Connection програм тухайн кассын компьютер дээр ажиллаж, терминал бэлэн байх ёстой.
  • Тооцоо амжилттай бол гүйлгээний тоо, дүн session-ий хуудсан дээр хадгалагдана.
  • Тооцоо амжилтгүй (эсвэл 120 секундэд хариу ирэхгүй) бол "Тооцоо хаагдсангүй" гэсэн мэдэгдэл гарч, session-ийг ямартай ч хаах эсэхийг асууна.
  • Менежер backend талаас session хаахад тооцоо автоматаар хаагдахгүй: зөвхөн кассын POS дээрээс хаахад ажиллана.
